# 轻记 · 个人记账 Web 应用

按 [轻记 PRD v1.1](../轻记-个人记账Web应用-PRD-v1.1.md) 实现的 v1.0 原型：响应式网页，手机浏览器优先，无后端、无注册，数据保存在浏览器 IndexedDB 中。

## 运行

**方式一：双击 `start.command`**（macOS）
会在当前目录启动 `http://localhost:8000` 并打开浏览器。

**方式二：手动启动**
```bash
cd qingji-web
python3 -m http.server 8000
```
然后访问 <http://localhost:8000>。

> 必须通过本地服务器访问，不要直接双击 `index.html`：浏览器的 `file://` 协议可能禁用 IndexedDB，导致数据无法保存。

## 已实现（v1.0 P0）

- 快速记账：支出 / 收入、金额、分类（支持二级分类）、日期、备注
- 智能预选：按最近使用、时间段、备注关键词推荐分类
- 账目管理：按日分组、月度概览、编辑、左滑删除、5 秒撤销
- 分类管理：默认分类、自定义一级/二级分类、改名、换图标/颜色、排序、隐藏、删除迁移
- 统计：月 / 年、支出 / 收入、环形分类占比、分类排行、近 6/12 个月趋势、分类下钻、数据表
- 数据：JSON 完整备份导出、CSV 导出、导入覆盖恢复、复制备份内容、备份提醒、清除数据
- 响应式：手机底部导航 + 悬浮按钮；桌面顶部导航 + 两栏首页
- 视觉：粉嫩奶油配色、圆角、粉色浅阴影、「小桃」品牌形象、深浅色对比校验
- 可访问性：键盘操作、焦点环、图表文字标签与数据表、`prefers-reduced-motion`

## 数据说明

- 所有数据仅保存在当前浏览器的 IndexedDB 中，不会上传。
- 清除浏览器数据、使用无痕模式、或某些浏览器自动清理存储，都可能导致账目丢失。
- 请定期在「我的 → 数据与备份」导出 JSON 备份。
- 换设备时：旧设备导出备份 → 新设备打开网页 → 导入备份。
- iOS 上把网页「添加到主屏幕」可能使用与 Safari 隔离的存储；安装前请先导出备份。
