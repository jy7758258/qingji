# 轻记 · 视觉规范与 Token

本文件是对 `assets/css/tokens.css` 的说明。页面中优先使用 CSS 变量与组件类，不直接写颜色值。

## 1. 视觉方向

- **关键词**：奶油粉、樱花、软糯、圆润、轻松、温柔。
- **比例**：大面积暖白/奶油粉背景，白色卡片承载数据，粉色只做按钮、图标、状态和少量装饰。
- **原则**：可爱服务于「愿意打开」，不能牺牲金额、分类、日期的可读性。
- **避免**：大面积高饱和亮粉、浅粉底上的白色小字、只靠颜色区分收支、过量阴影和装饰。

### 对比度约束

- 正文使用 `--text`（在 `--bg` 上对比度约 12:1）。
- 主按钮使用深玫瑰渐变（`#C73E6D → #A32E59`）配白字；不要用 `--primary` 浅粉配白字。
- 浅粉底上使用 `--primary-strong` 或 `--text`，不要使用白色小字。
- 图形可以低对比，但必须有文字标签或数据表兜底。

## 3. 图表色板

图表颜色仅用于区分分类，不用于正文。按固定顺序取色：

| 序号 | 色值 | 说明 |
| --- | --- | --- |
| 1 | `#E87BA4` | 玫瑰粉 |
| 2 | `#2A78D6` | 湖水蓝 |
| 3 | `#EB6834` | 蜜桃橙 |
| 4 | `#1BAF7A` | 薄荷绿 |
| 5 | `#EDA100` | 蜂蜜黄 |
| 6 | `#6250D6` | 鸢尾紫 |
| 7 | `#008300` | 叶绿 |
| 8 | `#E34948` | 珊瑚红 |
| 其他 | `#C9BBC1` | 灰粉 |

- 图表必须同时提供文字标签、金额/占比和 `<details>` 数据表。
- 不要把色板当作装饰色用于大面积背景。
- 新增图表色板时需做色盲/对比度校验。

## 4. 字体与数字

```css
--font-sans: "Avenir Next", "PingFang SC", "Hiragino Sans GB", "Noto Sans SC", "Microsoft YaHei", sans-serif;
--font-num: "Avenir Next", "DIN Alternate", "Plus Jakarta Sans", "PingFang SC", sans-serif;
```

- 中文正文优先系统字体，避免依赖外部字体 CDN。
- 金额、日期、统计数字使用 `.num` 或 `--font-num`，并开启 `font-variant-numeric: tabular-nums`。
- 正文 13–15px，辅助 10–12px；移动端输入框字号保持 16px，避免 iOS 聚焦放大。
- 标题字重 700–800；正文 400–650；不使用卡通中文字体承载正文。

## 5. 圆角与阴影

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius-xl` | `28px` | 主卡片、认证卡片 |
| `--radius-lg` | `22px` | 普通卡片 |
| `--radius-md` | `16px` | 次级面板 |
| `--radius-sm` | `12px` | 小控件 |
| `--pill` | `999px` | 按钮、标签、筛选项 |
| `--shadow-card` | `0 12px 40px rgba(165,44,95,.06)` | 主卡片 |
| `--shadow-soft` | `0 6px 18px rgba(165,44,95,.04)` | 次级卡片 |
| `--shadow-button` | `0 10px 24px rgba(165,44,95,.22)` | 主按钮 |

- 大面积卡片使用轻阴影 + 1px 粉色描边，不使用厚重灰阴影。
- 主要视觉记忆点是「小桃」贴纸、粉色渐变按钮与奶油粉纸张质感；其余保持克制。

## 6. 布局

- 内容最大宽度：`1240px`；页面左右留白：移动端 20px，桌面 28px。
- 顶栏高度：76px（桌面）/ 64px（移动端）。
- 断点：
  - `< 640px`：单列、紧凑卡片、底部导航。
  - `640–899px`：单列加宽，底部导航。
  - `≥ 900px`：顶部导航、隐藏底部导航与悬浮按钮。
  - `≥ 1000px`：明细/统计/设置使用双栏布局。
- 所有页面根目录，资源使用 `assets/...` 相对路径。

## 7. 组件与状态

- 按钮：主按钮使用深玫瑰渐变；次按钮为白底描边；危险操作用浅莓红底。
- 表单：聚焦时使用 3px 柔粉焦点环；错误文案放在字段下方，不只靠颜色。
- 分类图标：淡彩圆角底 + 线性 SVG 图标，尺寸 34–48px。
- 图表：环形图提供中心总额、分类排行和数据表；趋势柱提供月份标签与选中值。
- 动效：150–240ms；只用于打开弹层、切换状态、保存反馈；尊重 `prefers-reduced-motion`。

## 8. 可访问性

- 所有交互控件有可见焦点环；图标按钮必须有 `aria-label`。
- 页面保留 `<h1>`（子页面可用 `.sr-only` 或页面标题），表单 `<label>` 与输入框关联。
- 不使用颜色作为唯一信息通道：收入/支出、超支、选中状态同时有文字或图标。
- 触摸目标不小于 44×44px；移动端输入框 16px 字号。
- 模态框关闭后焦点回到触发元素；支持 `Esc` 关闭和 Tab 焦点循环。
